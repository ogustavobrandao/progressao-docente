# Progressão Docente

Sistema de auxílio aos docentes na organização, cálculo de pontuação e preparação da documentação necessária para processos de progressão acadêmica.

## Tecnologias

- Angular
- Tailwind CSS
- Hono
- Node.js
- TypeScript

## Estrutura do projeto

- `frontend/`: aplicação web desenvolvida com Angular.
- `backend/`: API desenvolvida com Hono.

## Pré-requisitos

- Node.js
- npm
- Git

## Instalação

`npm run install:all`

## Desenvolvimento

`npm run dev`

## Serviços

- Frontend: http://localhost:4200
- Backend: http://localhost:3000
